# 家里有一台一直亮着的小服务器，生活会很不一样

![家用服务器](https://images.unsplash.com/photo-1558494949-ef010cbdcc31?auto=format&fit=crop&w=1600&q=80)

当照片、自动化、备份、智能家居和个人工具开始往一台小服务器上聚拢，变化并不是家里突然多了多少“高级功能”，而是许多原本零散的小事终于有了固定去处。

手机拍下的照片可以定时备份，Home Assistant 不再依赖某一部手机在线，下载、文件共享、网络统计和消息推送也都有一台长期运行的设备负责。它像一间很小的机房，却服务的是最普通的家庭生活。

## 它真正解决了什么

我最看重的不是算力，而是持续在线。电脑会合盖，手机会离开家，路由器适合负责网络却不适合承担太多应用；一台低功耗主机则可以把这些长期任务稳定接住。

适合放上去的服务通常有：

- 照片与重要文件的自动备份
- Home Assistant、Homebridge 等家庭自动化服务
- Docker 容器、个人网页和轻量数据库
- 网络流量统计、设备状态监控与消息通知
- 局域网文件共享、下载和影音索引

但“集中”不等于把所有东西都塞进去。路由、重要备份和家庭自动化最好保留必要的故障隔离，避免一个系统重启，全家的网络和灯光同时失效。

## 选择硬件时，稳定比性能重要

家庭服务器大多数时间并不满载。比起追求更强的处理器，我更在意待机功耗、硬盘可靠性、散热、噪声和断电后的恢复能力。一台安静的 Mac mini、小型 x86 主机或成色良好的商用迷你机，往往比高功耗旧电脑更适合长期运行。

内存要给容器和文件缓存留余量；系统盘与数据盘尽量分开；有条件可以加 UPS，但更重要的是设置来电自启、定期更新和磁盘健康提醒。

## 备份不能只放在这台机器里

服务器不是备份本身。硬盘损坏、误删除、勒索软件和整机故障都可能让“集中存储”变成单点风险。我更认可 3-2-1 思路：至少保留三份数据，使用两种介质，其中一份在异地或云端。

照片原片、家庭证件和孩子成长记录值得更严格的策略；影视缓存和随时能重新下载的内容则没必要占用同等级备份资源。先给数据分级，成本和维护都会清楚很多。

## 维护应该尽量无感

家庭服务器最怕变成一个需要每天照料的新爱好。服务用 Docker Compose 记录配置，重要目录定期备份，更新前先看变更说明，再配一个简单的可用性提醒，已经足够覆盖大多数情况。

真正好的家庭服务器不会不断提醒你它的存在。它只是一直在那里，把照片收好，把自动化跑完，在某个设备离线时发来一条消息。技术退到生活后面，这才是它最舒服的状态。
